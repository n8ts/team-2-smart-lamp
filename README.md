# team-2-smart-lamp
Цель проекта: разработка и создание умной лампы
  
  Лампа в режиме реального времени при помощи датчика освещения измеряет уровень освещенности в аудитории и на основе этих данных регулирует уровень освещения.

MVP 

  Сцены освещения
  
    Реализация трех режимов: "работа", "отдых", "ночник" с уникальными параметрами яркости и цвета
 
  Автояркость
  
    Автоматическая корректировка яркости на основе показаний датчика освещенности в режиме реального времени

  Плавные переходы
  
    Анимированные смены между сценами без резких изменений освещения для комфортного восприятия

  Сохранение состояния
    
    Автоматическое восстановление последнего выбранного режима и яркости после перезагрузки устройства

Сиуляция лампы запускается в браузере
